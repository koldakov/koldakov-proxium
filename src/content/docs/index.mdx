```bash
docker run -d --name proxium -p 80:80 -p 8080:8080 -v proxium:/var/lib/proxium \
  -e SUPERUSER_CREATE=true -e SUPERUSER_EMAIL=admin@example.com -e SUPERUSER_PASSWORD=change-me \
  ikoldakov/proxium
```

<Image src={policyRules} alt="Policy rule: 1 Mbit/s in working hours, except work sites" />

A policy rule: 1 Mbit/s in working hours, except GitHub and Atlassian. Applies in seconds, no restart.
